# Ingestion and A4/A5 producer acceptance

The pinned R1 validator rejects tampered bundle bytes, invalid OCR quoting, uncorroborated candidate review claims and restricted references in the tested records. It accepts a document whose claimed original is absent from a complete synthetic release. It also accepts a candidate anchored to an unrelated bundled copy at a nonexistent page. These probes expose open end-to-end integrity criteria that R1 alone does not enforce. R1 §8 already assigns verification against source bytes to the importer. The deployment acceptance case must prove rejection before making a generation available.

The pinned A4 temporal resolver preserves uncertainty, disagreement and expressly stated retrospective dates. Its date-only result cannot determine which legal or factual scope governs. The pinned A5 builder can represent distinct proceedings and proposition-target treatment, while the R1 record surface has no native provision-version or graph-node type and cannot carry the full tested proposition scope in a holding payload. A4/A5 integration remains blocked pending a demonstrated mapping with a disposition for unsupported records.

## Open failure reproduction and ownership

- **DA-01, DA-04 and DA-35:** `DA-01-unbound-original`, `DA-01-missing-original`, `DA-04-outside-page` and `DA-35-cross-bound-anchor` each print `R1 accepted` in the command above. At R1, `bundle.py:190` checks the checksum list against file contents and `bundle.py:300` and `:328` track document IDs and source hashes as independent sets. `rules.py:246` checks page existence and reversed ranges without bounding offsets by the declared page length. B1/B2 importer acceptance must specifically prove claimed original and original/image/derivative binding. If validation is strengthened upstream, use the same fixtures for confirmation.
- **DA-32 and DA-33:** A5's producer schemas declare a general `attributes` object and nullable citation target fields. The positive specimens exercise the actual builder with the intended inputs. The negative specimens show that shape validation alone admits data missing scope or both target fields. A5 must evidence actual extraction and preservation. The importer must enforce or defer missing required research context.
- **DA-21 through DA-24 and DA-31 through DA-35 interface coverage:** R1's `schemas.py` has neither `provision_version` nor `graph_node` record kind. Some A5 citation records have a safe narrow projection. The demonstrated projection covers only a citation. Preserve candidate restrictions and defer legal-effect claims that lack a supported mapping. A4/A5/B1 owners need a demonstrated disposition for every record family before claiming interoperability.
