### Portable scorer

`python3 retrieval_oracle.py --observations path/to/observations.json` reads a JSON object keyed by all 14 RET IDs. For example, the entry for RET-01 is `"RET-01": {"mode":"identifier","state":"results","ranking":["A-17"]}`. Use `lexical`, `hybrid`, `identifier` or `parser_error` for the observed execution path, and `results`, `empty` or `parser_error` for outcome state. Keep ranked passage IDs in service order, up to 20, including irrelevant hits. Keep hidden and unexpected items in the capture. They are failure evidence. If the adapter cannot map a returned passage, retain it with an unknown ID and file a mapping or service defect. Measure flat passage order here, and assess document grouping independently. The scorer returns 0 when all hard assertions hold, 1 when any fail, and 2 on invalid input. Missing cases are invalid. The JSON output reports rank assertions and per-query/macro metrics. UI labels, response details and original bytes need independent inspection.

A grade of 3 denotes direct answer-bearing or exact-source evidence, 2 strong contextual or exact-identity evidence, 1 a useful indirect pointer, and 0 irrelevant. For identifier rows the exact metrics count grades 2–3. Precision@5 uses five slots even for short lists. Recall@10/20 divides hits with grade ≥1 by the labelled positive set. MRR uses the reciprocal rank of the first relevant item through rank 20. nDCG@10 uses exponential gain and normalizes against the ideal order. Empty/error cases are tested separately and excluded from macro ranking metrics. Deduplication in metric calculation avoids inflated credit. Duplicate ranked passage IDs still fail the hard assertion.

- **RET-LOCAL-01** / CAP-US-01, CAP-US-02, CAP-US-03, CAP-US-07 / P2. DEV status **Passed (oracle only)**. Input is the fixture and generated ideal/negative observations. Report the shortfall explicitly and keep the P2 gate open unless the owner records and accepts a dated ADR disposition. If recommending an external BM25 index, assess the ADR’s proposed ≥5 percentage-point material gain and generation consistency. Set any additional quantitative floors, including acceptable slice regression and anchor/retrieval fallbacks, before freeze. Exact-identity substitution, restricted/withdrawn leakage, unsupported authority claims and other hard failures fail their cases regardless of aggregate scores.
