# V4 development evaluation (IN-SAMPLE, spent sets only)

**Not a blind estimate.** Every judgment scored here was available to the V4 developer. The formal evaluation on the
fresh holdout H-OUT-C13 is run by an independent evaluator with `tools/extract_v4.py ids`. Generated by
`tools/eval_dev_v4.py --write --exclude-ids EXCLUDE_IDS_H-OUT-C13.txt` (no development judgment is in the exclusion
list). Rows: `DEV_EVALUATION_V4_ROWS.csv`; summary: `DEV_EVALUATION_V4_SUMMARY.json`.

## Sets and protocol

- **C12H**: the spent C12 V3 holdout (150 judgments, 215 rows), scored with the C12 pre-registered protocol (same
  `key()`, matcher and unscorable labels). The tool checks that it reproduces the published frozen-V3 result
  (126/138 printed, 108/113 substantive): it does.
- **TUNE / LATE**: C12H split by sha256(holdout_id) mod 3. The developer looked at TUNE errors only. LATE rows were
  never displayed during development and LATE was scored as a set at the end. Caveats: LATE aggregate figures appeared
  in the developer's evaluation tables during development (not used for any rule), and the V3 review files the
  developer read discuss some LATE judgments (for example V3H041).
- **DEVG**: `extractor_v3/tools/dev_gold_v3.json` (C10 50, the spent C11 holdout 56, C11R 30). Row-level: a gold `ALL`
  matches every predicted row; `#N` matches by number; correct only if every answered matched row carries an accepted
  label. This set was V3's own development gold, so V3 is also in-sample on it.
- V2 is scored from its frozen output (one outcome per judgment; substantive by default mapping).

## Failure categories: where the coverage gap is

Printed field, all spent sets, V4: 36 rows `PROCEEDING_UNMATCHED` (24 of them in two C12H judgments: V3H035 has no text
file at the c7 commit, and V3H039, a 15-row batch, is not resolved), 28 abstentions. Main abstention reasons:
no operative cue in garbled or old OCR text (6), no disposition found (4), only past/conditional wording (3), no
printed disposal words where only a set-aside is ordered (3), carve-outs (2), misc applications only (2), no text (2).

Substantive field: 53 abstentions, mostly `DISPOSED_OF_WITHOUT_DETERMINABLE_RESULT` (a "disposed of with directions"
whose effect on the relief sought is not stated in a form the rules can read). The gold labels in those rows are
mixed (relief_partly_granted, relief_granted, no_adjudication, relief_refused, interim_only), so no default is safe.

## Confidence tiers

All 6 errors are in the `high` tier (printed 191/195 high, 106/106 medium, 51/51 low). The tiers are therefore **not
calibrated** and must not be read as probabilities. They describe how the evidence was found, nothing more.
