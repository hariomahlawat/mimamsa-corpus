# Documentary corrections to frozen texts

Empty at version 0.

Corrections to frozen Cycle 4 or Cycle 5 **texts** (a report sentence, a docstring, a master title; for example C5-CO-01..05 in `C6-PREP/C5_CARRYOVER_CORRECTIONS.md`) are not authentication entries. Each is recorded, after an owner decision, in an append-only `notes.csv` here with these columns:
- `note_id`, `target_file` and `location`;
- `frozen_text`, `corrected_statement` and `evidence`;
- `decision_record_ref`.

Exports show the note beside the frozen text. The frozen file itself is never edited.
