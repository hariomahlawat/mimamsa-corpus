## Acquisition priority rule (mechanical)
- **EXCLUDED**: the route uses `aftjabalpur.in` or a bare-IP host. Never contact it. Only one item is excluded: ACQ-01 B5, AFT listings whose PDFs sit on the bare IP `103.154.2.123` over HTTP. No pending item touches aftjabalpur.in.
- **P0**: the item unblocks a reserved item, or the source recorded priority P0. An item unblocks a reserved item when its dependents, its target or its derived provisions match r.23/C-01/R23-VERIFY, r.193/C-08, r.194/C-09, r.15/OQ-A-10/GAP-15/XC-03, r.187/OQ-A-11/GAP-14/OQ-C-06, or s.129/CC-17/FID-03.
- **P1**: the source recorded priority P1 (or 1); or the source is located and its integrity is pinned; or (WS-B only) the item unblocks a record in the calibration sample.
- **P2**: everything else. A recorded P3 maps to P2. An item recorded as *optional* (ACQ-C3-02, ACQ03-016) is capped at P2.
- **`proposed_sequence`** sorts by priority, then source located, then integrity pinned, then scope (ACQ-01 → ACQ-02 → ACQ-03 → WS-A C3 → WS-B), then ID.
- **Approval scopes are unchanged.** Each batch still needs its own configuration PR approval and then its own download-run approval. ACQ-01 is PR #8, ACQ-02 is PR #17, ACQ-03 is PR #23; none is merged into `claude/integration-cycle3`. ACQ-C3-* and WS-B items have no configuration PR.
- Counts: P0 29, P1 66, P2 39, EXCLUDED 1. Source located: 90. Integrity pinned (sha256/md5 + bytes): 69.

## Affected-record score (mechanical)
`score = 2 × provisions + 1 × unstated + 3 × cases + 5 × reserved + 4 × calibration`

- **provisions**: Army Act sections and Army Rules cited by the record (WS-C `kb658_source_coverage_inventory.csv`) whose WS-A `statutory_version_completeness_cycle3.csv` status starts with `NOT_ESTABLISHED` or `PARTIALLY_ESTABLISHED`.
- **unstated**: distinct provisions with an edge in WS-D `relation_graph_versioned_edges.csv` that is flagged `EFFECTIVE_DATE_UNSTATED` or whose status starts with `NOT_`/`UNKNOWN`.
- **cases**: linked judgments (WS-B crosswalk and cycle-3 name links) with no official copy held, or listed in `pending_acquisition_cycle3.csv`.
- **reserved**: reserved provisions the record cites.
- **calibration**: 1 if the record is in CALIBRATION-01.

Ties are broken by breadth: the sum of `kb_records_citing` over the affected provisions plus the number of records linked to each unresolved case. The final tie-break is `record_id`.

`unblocked_by_acq_ids` links each affected provision to the items whose dependents name the same AR or AA register IDs, Act number/year, open-question or conflict IDs, or the acquisition ID itself. It also links each case to its WS-B queue IDs. Global register gaps (AR-001/030/036, the hints, AA-02/04/07) bear on every Army Rule or every Army Act section; they appear in the schedule's `blocking_dependents` and are not repeated on every record.

Results: 349 records. 280 have incomplete statutory history, 109 have unstated effective dates, 78 have unresolved case law, 36 involve a reserved item and 35 are in the calibration sample. The top 10 are KB-030, HCE-002, CIV-002, CM-CL-04, HCE-001, CM-001, HCE-033, CM-CL-01, CM-CL-06 and CM-CL-02.

## Authentication queue priority
- **MML**: P0 if the file is named in a WS-C procedural contradiction (`procedural_contradictions_cycle3.csv`) that touches a reserved item. P1 if it is named in a P1 contradiction. Otherwise P2.
- **Judgments**: P0 if WS-B recorded P0 or a linked record is in the calibration sample. P1 if WS-B recorded P1 or the holdings pinpoints are read from a mirror copy. Otherwise P2.
- MML authentication needs the owner or a custodian. No acquisition ID exists for it, and agents send no correspondence.
